# 🚀 Developer Task Dashboard

A modern and responsive **Developer Task Dashboard** built with **HTML, CSS, and JavaScript**.

This project helps developers keep track of their weekly learning goals while practicing responsive design and DOM manipulation.


## ✨ Features

* 📊 Interactive progress bar
* ✅ Track completed tasks
* 📈 Dashboard statistics
* 🎨 Modern and responsive UI
* 🏷️ Colorful technology badges
* 💻 Mobile-friendly design
* ⚡ Dynamic updates with JavaScript
* ♿ Accessible and semantic HTML

---

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript (ES6)
